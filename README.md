# CampusBite 🍴

A simple and user-friendly campus food pre-order system designed to make ordering food on campus convenient and hassle-free.

## 📌 About the Project

CampusBite is a web-based food pre-ordering system developed as a mini project.

The idea is to allow students to browse food items, add their choices to a cart, and view their order before placing it.

The current version focuses on the frontend interface and user experience. Backend and database integration are planned for future development.

## ✨ Features

-  Simple and attractive home page
-  Browse available food items
-  Add food items to the cart
-  Increase or decrease item quantity
-  Remove items from the cart
-  Automatic calculation of cart total
-  Responsive layout for different screen sizes
-  Clean and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and responsive design
- **JavaScript** – Cart functionality and user interactions
